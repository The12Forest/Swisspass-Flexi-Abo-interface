Browser Extension

Die Extension synchronisiert automatisch Cloudflare-Cookies und Refresh-Tokens mit diesem Server.

Extension herunterladen

Installation (Chrome/Edge):

  1. ZIP herunterladen und entpacken
  2. chrome://extensions öffnen
  3. Entwicklermodus aktivieren
  4. «Entpackte Extension laden» → Extension-Ordner auswählen

Installation (Firefox):

  1. about:debugging#/runtime/this-firefox öffnen
  2. «Temporäres Add-on laden» → manifest.json
