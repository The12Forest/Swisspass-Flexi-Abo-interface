🌐 Server URLs

Der Server läuft auf zwei Ports gleichzeitig:

  • HTTPS https://<server-ip>:3443
    → Für diese Browser-Extension verwenden
  • HTTP http://<server-ip>:3001
    → Für Home Assistant (HTTP, kein Zertifikat nötig)
🔒 HTTPS Zertifikat (einmalig)

Das Zertifikat wird beim ersten Serverstart automatisch generiert. Du musst es einmalig im Browser akzeptieren:

1
Öffne https://<server-ip>:3443 im Browser.
2
Klicke auf „Risiko akzeptieren und fortfahren".
3
Trage die HTTPS-URL in der Extension ein und klicke Speichern.
🏠 Home Assistant
  • Server-URL im HA-Setup: http://<server-ip>:3001
  • Button „Activate Today" erscheint nach HA-Neustart
  • Integration download: /api/ha-integration/download
